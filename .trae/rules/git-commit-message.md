# Git 提交信息规范

## 格式要求

- 使用中文简体
- 使用祈使语气（如"添加"而非"添加了"）
- 保持简洁，第一行不超过 50 字符
- 详细说明放在正文部分

## 类型前缀

- `feat:` 新功能
- `fix:` 修复 bug
- `docs:` 文档变更
- `style:` 代码格式（不影响功能）
- `refactor:` 重构
- `perf:` 性能优化
- `test:` 测试相关
- `chore:` 构建/工具变更

## 示例

feat: 添加用户登录功能

- 支持手机号+验证码登录
- 集成第三方登录
- 添加登录日志记录

## 规范

- 不要以句号结尾
- 重要变更使用 `!` 强调（如 `feat!:`）
- 关联 issue 时使用 `(#issue号)`
